# System Architecture

## Основные модули

- Web App
- API Backend
- User Service
- Property Service
- Tenant Demand Service
- Matching Service
- Notification Service
- Deal Service
- Payment / Escrow Service
- AI Manager Service
- Admin Panel

## Главный принцип

Система строится вокруг событий сделки, а не вокруг страниц интерфейса.
